隐私政策

自然拾光科技（广州）有限公司 · 版本 2.0 · 生效日期：2026-02-01

核心承诺：「自然拾光记账」采用本地优先设计。您的账套、发票、员工与薪酬等经营数据默认仅保存在本机，我们不会收集、上传或存储这些业务数据到我方服务器。

一、适用范围

本政策适用于您安装、使用「自然拾光记账」桌面客户端过程中，我们对信息的收集、使用、存储、共享与保护。本政策不适用于通过本软件访问的第三方网站或服务。

我们遵循《中华人民共和国个人信息保护法》《中华人民共和国数据安全法》《中华人民共和国网络安全法》等法律法规，按照合法、正当、必要和诚信原则处理信息。

二、我们如何处理信息

2.1 业务数据（本地存储，不上传）

下列数据用于完成记账与管理功能，默认仅存储在您的设备，我们不收集、不上传：

信息类型示例处理方式
账套与流水收支记录、分类、备注、对手方、账户余额本地数据库存储
发票与票据发票影像、OCR 识别结果、发票号码、金额本地存储与解析
公司档案名称、纳税人识别号、注册地址等开票要素本地存储
用工与薪酬员工姓名、身份证号、工资、个税预估、劳务记录本地存储
银行流水您主动导入的 CSV 等文件内容本地解析与匹配
备份文件本地备份包、AES-256 加密备份包由您自行保管

2.2 设备与诊断信息（极少量，用于排障）

软件运行崩溃或异常时，可能在本地生成错误日志，用于您自行排查或向我们反馈。我们不主动建立云端日志收集。若您通过邮件或在线渠道主动提交日志，仅用于问题定位，不作其他用途。

2.3 更新检查（可选）

若您使用“检查更新”，软件可能访问更新源获取版本信息。该过程仅用于比对版本号，不附带您的账套或票据内容。

2.4 AI 助手（可选，需您主动开启）

  • 默认关闭。仅在您自行配置第三方大模型 API Key 后才可使用；
  • 为回答您的问题，可能将您主动选中或输入的文本片段发送至您配置的服务商；
  • 我们不会在未告知的情况下批量上传账套；相关传输受您与该服务商的协议约束；
  • 您可随时删除 API Key 并关闭该功能。

2.5 邮箱收票 / 云端能力（可选）

若未来版本启用邮箱收票或云端同步，将在启用前单独说明数据范围、传输方式与保存期限，并征得您的同意。在此之前，相关能力不默认开启。

三、权限与功能对应

权限 / 能力用途是否可拒绝
文件读写导入银行流水、发票图片；导出报表与备份可拒绝，相关功能不可用
通知申报截止提醒、待办事项可在系统设置中关闭
网络（更新 / 可选 AI）检查软件更新；在您配置后调用 AI 接口可不使用更新与 AI

我们不会申请与记账无关的通讯录、位置、麦克风、摄像头等敏感权限。

四、第三方组件与 SDK

  • Microsoft Edge WebView2：提供桌面界面渲染能力，由 Microsoft 按其隐私政策处理诊断数据（您可在 Windows 设置中调整诊断级别）；
  • OCR / 模型服务：若使用云端识别，仅在您触发识别时传输对应票据图像；本地能力优先；
  • 大模型 API：仅在您配置并启用后，按您的指令传输文本。

我们不向任何第三方出售您的个人信息。

五、数据存储与安全

  • 存储期限：业务数据保存在本地，由您决定保留时长；删除或卸载后可彻底清除；
  • 加密能力：提供 AES-256 加密备份包，口令由您保管，丢失无法恢复；
  • 安全措施：软件设计避免明文外传；本地数据库建议置于用户目录，由系统账户权限保护；
  • 跨境传输：默认不发生跨境传输。若您自行配置境外 AI 服务，属您自主行为。

六、您的权利

按照适用法律法规，您享有以下权利：

  • 查阅、复制：在软件内查阅全部业务数据，导出 CSV、报表、文书；
  • 更正、补充：编辑流水、档案、员工等记录；
  • 删除：删除单笔记录、账套或卸载并清除数据目录；
  • 撤回同意：关闭 AI、通知、更新检查等可选功能；
  • 获取副本：通过备份功能导出完整账套。

由于数据在您本地，上述权利大多可由您在软件内直接行使，无需向我们申请。

七、未成年人

本软件面向具有完全民事行为能力的经营者与用户。若您为未成年人，请在监护人指导下使用。我们不会故意收集未成年人个人信息。

八、政策更新

  • 本政策可能适时修订，并在本页标注生效日期；
  • 涉及处理目的、信息类型、共享对象等重大变化时，将通过软件内提示等显著方式告知；
  • 您继续使用视为接受更新后的政策。
