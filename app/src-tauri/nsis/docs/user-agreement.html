一、协议主体与适用范围

本协议是您与自然拾光科技（广州）有限公司（下称“我们”或“公司”）之间，就下载、安装、使用本软件及相关服务所订立的协议。

本软件面向个体工商户、小微企业主、自由职业者及家庭记账用户，用于日常收支记账、票据管理、用工与薪酬记录、税务申报辅助等经营与财务管理场景。

二、软件功能与定位

本软件为本地优先的桌面记账工具，主要功能包括（以实际上线版本为准）：

  • 流水记账：收入、支出、调拨、冲销、借款等事项录入与分类；
  • 账户管理：银行、现金、第三方支付等多账户余额与转账；
  • 票夹与发票：发票上传、OCR 识别、票据归档与报销单；
  • 银行流水导入：CSV 等格式导入并与账目智能匹配；
  • 劳务用工：临时用工、正式员工档案、工资与个税预估；
  • 税务申报辅助：申报日历提醒、税费试算、申报表格包导出；
  • 文书生成：收据、协议、借据、结算单等常用文书；
  • 备份与加密：本地备份、AES-256 加密备份包；
  • 智能助手（可选）：您自行配置 API Key 后，可启用规则建议、票据问答等 AI 能力。

本软件不是电子发票开具平台、税务申报官方通道，亦不替代会计师事务所、税务师事务所的专业服务。
