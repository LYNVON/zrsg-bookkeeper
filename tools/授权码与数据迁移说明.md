# 授权码签发与数据迁移说明

## 1. 私钥保管（最重要）

- 私钥文件：`tools/license-gen/license-key.txt`
- 已加入 `.gitignore`，**不会进仓库**
- **务必单独备份到离线位置**（U 盘 / 密码管理器）。丢失后：
  - 无法再为已装用户续期或换机（因为旧授权码是用这把私钥签的）
  - 重新生成密钥对会导致**已发出的授权码全部失效**
- 公钥已内置在 `app/src-tauri/src/license.rs` 的 `PUBKEY_HEX`，与私钥配套；改动私钥必须同步换公钥并重新发版。

## 2. 签发授权码

在项目根目录执行（首次会编译，约 1 分钟）：

```powershell
cd tools\license-gen
cargo run -q -- sign <机器码> <plan> [到期日]
```

- `机器码`：客户在「设置 → 软件授权」里复制给你（形如 `A1B2C3D4E5F60718`）
- `plan`：`personal`（个人版）/ `pro`（专业版）/ `trial`（延长试用）
- `到期日`：`2027-10-26` 这样的日期；省略或写 `*` 表示永久

示例：

```powershell
cargo run -q -- sign A1B2C3D4E5F60718 personal 2027-10-26
```

输出一行 `ZRSJ1.xxxx.yyyy`，把它发给客户，粘贴到「设置 → 软件授权 → 授权码」点激活即可。

- 授权码**离线校验**，不需要联网，也不需要服务器
- 绑定机器码：换电脑需要重新签发
- 通用码：机器码位置写 `*`（例如给内部测试用）

## 3. 客户换机 / 重装

客户在「设置 → 数据与备份」：

1. 点 **导出全部数据**，选一个目录。产出：
   - `zrsj.db`：完整账套
   - `attachments/`：全部发票原件
   - `manifest.json`：导出时间、机器码、票据与流水数量
2. 在新电脑装好软件，点 **从文件恢复**，选中导出的 `zrsj.db`
3. 恢复前会自动快照当前库，恢复错了可以在「恢复」下拉里退回

## 4. 试用与到期

- 首次运行自动开始 **30 天试用**（记录在数据库 `schema_meta.first_run`）
- 到期后：首页顶部出现横幅提示，**功能不锁死**（避免客户数据被卡住），建议尽快激活
- 如果想让到期后限制功能，改 `app/src-tauri/src/license.rs` 的 `status()` 并在前端拦写入

## 5. 后续要做账号登录时

当前是纯离线方案。要接手机号/微信登录，需要：
- 后端（域名 + 备案 + 服务器）
- 短信服务商报备 或 微信开放平台企业认证
- 授权令牌签发/吊销 + 设备管理

届时把 `license_status` 的判定改为"本机令牌 + 服务端令牌"二选一即可，数据加密仍留在本机，避免服务器故障导致客户账目打不开。
