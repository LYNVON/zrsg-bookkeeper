# 自然拾光记账客户端（zrsj-bookkeeper）

面向**个体工商户 / 小微企业主 / 自由职业者**的本地桌面记账与报税辅助工具。

- 单用户、单账套、数据全在本机（不上传服务器）
- 授权为本机离线授权码（绑定机器码，无需联网）
- 权威现状说明见 **[docs/产品与技术现状.md](docs/产品与技术现状.md)**；本文只做快速上手

## 功能概览

**记账主链**：记一笔（含税务状态）· 事项池 · 关联工作台（自动匹配 + 缺票处置）· 多账户与转账 · 银行 CSV 导入（幂等）
**票据与报销**：票夹卡片流 · **上传发票附件自动归档**（PDF 抽文本 / 扫描件与图片走内置 OCR）· 自动归类 · 原件完整性校验 · 多选生成报销单并打印 · 外部报销单识别 · IMAP 邮箱收票（UID 去重、自动收票）
**用工与工资**：临时用工（≤500 零星判定、三级劳务报酬预扣）· 劳务工单与工时 · 员工档案与工资单 · 绩效奖金
**税务与申报**：税费试算（增值税/附加/企税小微/劳务）· 申报日历与桌面提醒 · 申报表格包 · 季报底稿与历史
**文书**：收据 · 劳务协议 · 结算单 · 报销单 · 私车公用协议 · 借款借据
**数据安全**：自动备份（24h/保留 20 份）· 备份恢复（含从任意 .db 恢复，恢复前自动快照）· AES-256-GCM 加密备份 · **导出全部数据（换机迁移）**· 变更审计 · 崩溃日志
**授权**：离线授权码（Ed25519 签名、机器码绑定）· 30 天试用（到期提示不锁功能）
**报表**：经营报表（月度收支 / 收支构成 / 账户余额 / 应收应付）· 社保公积金比例配置与测算
**其他**：AI 数字财务总监（自带 API Key，双性格）· 经营简报 / 账龄 / 现金流与临界点提示

## 安装与发布

```
app/src-tauri/target/release/bundle/nsis/自然拾光记账_0.1.0_x64-setup.exe
```

安装包约 **32 MB**（含内置 Tesseract OCR 引擎，任何 Windows 10/11 可用，不依赖系统语言包）。

构建：

```powershell
cd app
npx tsc --noEmit          # 类型检查
npm test                  # 前端单测（vitest）
npx tauri build --no-bundle   # 产出 target/release/app.exe

cd src-tauri && cargo test --lib   # 后端单测

python tools/build_installer.py    # 打 NSIS 安装包
```

签名（可选，需要证书）：设置 `ZRSJ_SIGN_PFX` + `ZRSJ_SIGN_PFX_PASS`（或 `ZRSJ_SIGN_THUMBPRINT`）后重新打包，会自动调用 `tools/sign.ps1`。

## 快速开始

1. 首次运行会**引导录入公司档案**（名称 + 税号，可顺带生成默认申报任务）
2. 记一笔 或 票夹 → 上传发票附件（自动识别归类）
3. 设置 → 邮箱自动收票（QQ 邮箱需生成 IMAP 授权码）
4. 税务申报 → 试算 / 生成申报表格包
5. 设置 → 数据与备份：立即备份、导出全部数据（换机时在新机「从文件恢复」）

## 环境

- Rust（stable）+ VS Build Tools 2022 + Node 22
- 前端在 `app/`，Rust 在 `app/src-tauri/`，数据库 DDL 在 `db/schema.sql`
- 数据目录：`<安装目录>/data/`（不可写时回退 `%LOCALAPPDATA%/自然拾光记账/data/`）

## 数据与安全

- 账套使用 **SQLCipher 加密**，密钥 `data/key.bin` 由 Windows DPAPI 保护（同账户可解，拷走文件不可用）
- `data/key.bin` 必须与账套一起备份；灾备请用「导出全部数据」（明文快照），换机后「从文件恢复」
- 单实例锁：重复启动只唤起已有窗口，避免两个进程同时写库

## 已知缺口

安装包未签名、自动更新需在设置里配置更新源（安装包未签名会有 SmartScreen 提示）、无凭证/总账等会计准则报表（现有简版经营报表）、发票查验未接入、无多账套与云端。
完整清单与优先级见 `docs/产品与技术现状.md` 第 6 节。
